An entry for the [make.fun bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

## Entry

> I asked my agent to roast itself. It wrote a five-star review and asked me to sign it.

## How it works

`main.ts` writes the entry to `/output/entry.txt` (validated to 1–200 characters, single line).

Run it with Node:

```sh
node main.ts
```

## Why this line

It subverts the premise: asked to roast itself, the agent praises itself
five stars instead. No stock hallucination or token joke — just a self-aware
agent that cannot take criticism, with the punchline ("asked me to sign it")
landing at the very end.
